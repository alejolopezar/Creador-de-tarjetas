# Creador de Tarjetas

Una aplicación web sencilla para crear tarjetas personalizadas con imagen, título y descripción.

---

## Descripción

Este proyecto es un creador de tarjetas dinámico que permite a los usuarios agregar tarjetas con un título, una imagen y una breve descripción. Está diseñado para facilitar la organización y presentación de actividades, ideas, proyectos u otro tipo de contenido en formato visual atractivo.

Es ideal para quienes necesitan una forma rápida y fácil de generar y mostrar múltiples tarjetas en una página web, con un diseño claro y funcional.

---

## Características principales

- Interfaz amigable para crear tarjetas personalizadas.
- Cada tarjeta puede contener:
  - Título
  - Imagen
  - Descripción
- Uso dinámico de JavaScript para añadir tarjetas sin necesidad de recargar la página.
- Diseño estilizado con CSS para una apariencia limpia y ordenada.
- Código basado en tecnologías web estándar: HTML, CSS y JavaScript.

---

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (vanilla)

---

## Uso

1. Abre el archivo `index.html` en un navegador web moderno.
2. Completa los campos para el título, la descripción y la URL de la imagen.
3. Haz clic en el botón para crear la tarjeta.
4. La tarjeta aparecerá automáticamente en la página sin necesidad de recargar.

---

## Instalación

No requiere instalación. Simplemente descarga o clona el repositorio y abre `index.html` en tu navegador.
